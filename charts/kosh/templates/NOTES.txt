kosh {{ .Chart.AppVersion }} is installed as {{ include "kosh.fullname" . }}.

Its endpoint ID:

  kubectl --namespace {{ .Release.Namespace }} logs deploy/{{ include "kosh.fullname" . }} | head
  kosh id --state-dir DIR     (on the state directory, or the Secret's files)

Connect:
{{- if .Values.ssh.enabled }}
{{- if eq .Values.service.type "LoadBalancer" }}

  ssh -t <address of the load balancer>{{ if ne (int .Values.service.port) 22 }} -p {{ .Values.service.port }}{{ end }}
  kubectl --namespace {{ .Release.Namespace }} get service {{ include "kosh.fullname" . }}
{{- else if eq .Values.service.type "NodePort" }}

  ssh -t -p <node port> <address of a node>
  kubectl --namespace {{ .Release.Namespace }} get service {{ include "kosh.fullname" . }}
{{- else }}

  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "kosh.fullname" . }} 2222:{{ .Values.service.port }}
  ssh -t -p 2222 localhost
{{- end }}
{{- end }}
{{- if .Values.iroh.enabled }}

  iroh-ssh kosh@<endpoint ID>
{{- end }}
{{- if and .Values.iroh.enabled .Values.iroh.hostNetwork .Values.ssh.enabled }}

iroh.hostNetwork puts the pod on the node's network: SSH listens on port {{ .Values.ssh.port }} of every address of the node, whatever service.type is.
{{- end }}

authorizedKeys is the list of who may connect. A key's name ends in its
role: name/<role> for a ClusterRole (alice@laptop/cluster-admin,
bob@laptop/view), name/<role>@<namespace> for a Role in that namespace
(carol/edit@team-a). A session has the rights of its key's role; kosh
makes the role's binding, named for this instance,
{{ include "kosh.instance" . }}. /admin is the ClusterRole admin, not
cluster-admin. kosh can grant no more than the ClusterRole
{{ .Values.rbac.clusterRole }} lets it.

Whoever can change the key list can give any key any of those roles.
A role that may write ConfigMaps in {{ .Release.Namespace }}, as the
ClusterRoles edit and admin may, can edit the list, and so grant itself
anything: keep {{ .Release.Namespace }} writable by cluster administrators
alone. kosh warns in its log of every role of the list that may.
