# kosh

A terminal UI for the Kubernetes cluster it runs in, in the manner of
[k9s](https://github.com/derailed/k9s), served over SSH and over
[iroh](https://iroh.computer) to whoever holds an accepted key.

kosh is being built. Its design is in
[`docs/superpowers/specs/`](docs/superpowers/specs/) and the plan of its
first stage in [`docs/superpowers/plans/`](docs/superpowers/plans/).
